# 🧪 نظام إدارة محاليل المختبر (Lab Inventory PWA) تطبيق ويب تقدمي (Progressive Web App) مفتوح المصدر مصمم خصيصاً للمختبرات الطبية لإدارة مخزون المحاليل والكواشف بدقة واحترافية. يوفر النظام تجربة مستخدم سلسة وسريعة مع إمكانية التثبيت على الهواتف الذكية (iOS & Android) كأي تطبيق محلي. ## ✨ المميزات الرئيسية * **📦 إدارة دقيقة للكميات:** التعامل مع المحاليل بنظام "العلب (Boxes)" و "الوحدات المفردة/الكارتلج (Cartridges)" لحساب المخزون الفعلي بدقة. * **🚀 حركات سريعة (سحب/إضافة):** أزرار مخصصة لسحب أو إضافة كميات من المخزون بضغطة زر مع حساب تلقائي للمتبقي. * **📂 تصفية حسب القسم:** فلترة سريعة للمحاليل حسب أقسام المختبر (كيمياء حيوية، أمراض دم، هرمونات، أحياء دقيقة، إلخ). * **📸 قراءة الباركود مدمجة:** دعم كامل لفتح كاميرا الهاتف الذكي لمسح باركود المحاليل للبحث أو الإضافة السريعة. * **⚠️ تنبيهات الصلاحية والنفاذ:** لوحة تحكم ذكية تعرض المحاليل التي قاربت على الانتهاء أو التي اقترب رصيدها من النفاذ. * **🔐 نظام صلاحيات الإدارة:** وضع خاص للمدير (برمز مرور) لحماية عمليات الإضافة والحذف، مع السماح للموظفين بالسحب والإضافة للرصيد فقط. * **📜 سجل حركات شامل (Logs):** تسجيل تلقائي لكافة العمليات (إضافة، تعديل، حذف، سحب رصيد) مع توضيح وقت العملية. * **⚡ أداء فائق:** استخدام تقنيات (Debounce) في البحث، وجلب البيانات المحدود (Limit Queries) لضمان سرعة استجابة فورية حتى مع آلاف الأصناف. * **📱 تطبيق تقدمي (PWA):** قابل للتثبيت على الأيفون والأندرويد للعمل بدون الحاجة لفتح المتصفح في كل مرة. ## 🛠️ التقنيات المستخدمة * **الواجهة الأمامية (Front-end):** HTML5, CSS3, JavaScript (ES6+). * **إطار التصميم (Styling):** Tailwind CSS. * **قاعدة البيانات والتزامن (Back-end):** Firebase Firestore (Real-time NoSQL Database). * **المصادقة (Authentication):** Firebase Auth (Anonymous/Custom Token). * **مكتبات مساعدة:** * `FontAwesome` (للأيقونات). * `HTML5-QRCode` (لقراءة الباركود عبر الكاميرا). ## ⚙️ طريقة التشغيل والتثبيت محلياً 1. قم بعمل استنساخ (Clone) للمستودع: ```bash git clone https://github.com/USERNAME/lab-inventory-pwa.git ``` 2. افتح ملف `lab-inventory-pwa.html` في أي محرر نصوص (مثل VS Code). 3. **مهم جداً (ربط Firebase):** ابحث عن متغير `firebaseConfig` داخل الكود، واستبدل القيم الوهمية (`demo`) ببيانات مشروع Firebase الخاص بك: ```javascript const firebaseConfig = { apiKey: "YOUR_API_KEY", authDomain: "YOUR_PROJECT_ID.firebaseapp.com", projectId: "YOUR_PROJECT_ID" }; ``` 4. قم بتشغيل الملف عبر سيرفر محلي (Live Server) لكي تعمل ميزات كاميرا الباركود وتخزين الـ PWA بشكل صحيح. ## 📱 التثبيت على الهاتف (PWA) * **أندرويد:** عند فتح الرابط سيظهر زر "تثبيت التطبيق" في الشريط العلوي. * **آيفون (iOS):** اضغط على زر (مشاركة) في متصفح سفاري، ثم اختر "إضافة إلى الصفحة الرئيسية (Add to Home Screen)". ##
